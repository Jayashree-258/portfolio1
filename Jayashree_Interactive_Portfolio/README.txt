JAYASHREE INTERACTIVE PORTFOLIO

OPEN:
1. Extract this ZIP.
2. Double-click index.html to open it in Chrome.
3. To edit, open this folder in Visual Studio Code.

FEATURES:
- Animated floating hero design and rotating text
- Scroll reveal effects and reading progress bar
- Responsive mobile navigation
- Light/dark theme toggle
- Animated skill bars
- Life Saver project details popup
- Contact form that prepares an email in your email app

PERSONALIZE:
- In script.js, replace your-email@example.com with your real email address.
- Update text and project information in index.html.
- Add your real social/profile links and photo if desired.

Note: The contact form uses mailto; it does not send messages to a server. Google Fonts needs an internet connection.
